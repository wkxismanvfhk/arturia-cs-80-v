## Overview

Arturia CS-80 V recreates the legendary Yamaha CS-80, the massive polyphonic synthesizer used by Vangelis, featuring dual sub-oscillators, a ribbon controller, and the iconic CS-80 filter.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia CS-80 V** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **CS-80 Filter** | Dual 12 dB/oct high-pass and low-pass filter per voice as in original |
| **Ribbon Controller** | On-screen ribbon controller for expressive pitch and vibrato |
| **Per-Voice Tuning** | Individual voice tuning and envelope for classic CS-80 analog drift |
| **Preset Library** | Faithful recreations of classic Vangelis and soundtrack CS-80 sounds |
